# Ground Glass regression semantics

## Finding

**Confirmed scene-content sensitivity.** The historical courtyard previews fail the whole-frame ratio with a valid current request, finite prepared uniforms, all five actual render passes, and identical sampled hero and foreground image statistics. Actual ray coverage changed. This qualifies the diagnostic finding. Historical release decisions still depend on physical clearance and the other scene checks.

## What is measured

| Signal | Owner and stage | What it proves |
| --- | --- | --- |
| Raw variance | The 32 × 32 RGBA8 copy of source color before CoC, gathers, composite, illumination and display orientation. | Variation in the sampled offscreen source colors. |
| Final variance | The 32 × 32 RGBA8 copy of the owned composite target. The composite includes the resolved Raw/Upright transform and, when processing is enabled, gather, near-layer composition and physical illumination/coverage. | Variation in the sampled post-composite bytes before the final canvas blit. |
| Raw/final contentful | The same sampled pixels. At least 95% alpha ≥240, at least max(4, 2%) sufficiently far in RGB from the fixed sky triplet, and variance ≥4. | A useful uniform or obviously empty buffer smoke check. The contentful fields and variance come from the same sampling. |
| Uniforms finite | The diagnostic records whether the current typed DOF render-state preparation succeeded. A failure logs a reason. The renderer can retain the last valid shader state. | CPU preparation validity for that diagnostic frame. |
| Raw RTT bypass | Source color goes directly to composite. CoC and both gathers are skipped, as are processed relative illuminance and coverage terms in this mode. The display orientation still applies. | An intentional alternative pipeline. Raw Ground Glass is an orientation control, and the diagnostic bypass is a separate control. |
| Frame readiness | Backend request, channel and generation select accepted runtime results. Frame completion is published after the required draw/blit path completes and context loss is checked. | The current request completed the application’s render transaction. A contentful bit or a UI bypass prop alone cannot establish state or pass identity. |

The copy shader samples the texture and writes it unchanged. The analyzer applies coefficients 0.2126/0.7152/0.0722 to stored 0–255 values and computes population variance. The result stays in sampled render-target byte units, with the final target already carrying composite illumination. The analyzer uses the stored values directly. In this replay, actual open-sky corner bytes were [188, 200, 214] while the analyzer compares [223, 229, 236]. Every 32 × 32 cell registered as “non-background” even in views with about half of the geometric film samples open. Use the geometric/depth coverage ledger when answering placement questions. The two 32 × 32 reads occur synchronously in one eligible frame. The state key gates re-sampling by optical inputs, canonical off-axis matrix, actual camera extrinsics, orientation, resource and subject generations. The actual effective clip is absent as a separate key input. A2 should carry effective render extent into identity and invalidation explicitly. The new-request completion properties and retained values during target resize mean that test readback and readiness are distinct. The existing Playwright test waits on contentful flags, then reads the two variances and repeats contentful checks when toggling Raw. The test samples published values without a current-request assertion or a pass-set check. The audit compared a same-frame source/composite tap, request matched to DOM current/last-completed IDs, with three distinct emitted frame sequence IDs. The measured sensitivity reproduced after readiness, with identical pairs across all three frames. ## Controls and next diagnostic contract

| Property | Proposed witness | Exercised in A0 |
| --- | --- | --- |
| Numerical validity | Require a present, finite typed prepared state and validate the physical coefficients/CoC where relevant. | An isolated numeric witness rejects NaN and Infinity. No shipped fault injection. |
| Availability and blank output | Retain clear/uniform detection in an explicit expected-content fixture. Use a depth or known sentinel occupancy reference when classifying empty background. | An opaque uniform 32 × 32 buffer has zero variance and fails the current criterion. The Ray ledger illustrates the RGB heuristic saturation. |
| Current state | Tie readiness, pixels, pass record, subject identity and any applicable extent/variation to the accepted request and generation. Capture after completion. | An actual 7740 mm frame would pass the global ratio when offered for a 7750 mm request. An identity check rejects it. |
| DOF actually ran | Require the actual scheduled CoC, far/near gather and composite stages for processed mode, and a known nonzero optical-response witness. | Public Raw RTT bypass genuinely skips three stages. The resulting 1.0 ratio passes the old assertion. |
| Correct blur and occlusion | Fixed multi-depth patterns with analytically known CoC, normalized local edge response and foreground-contamination controls. Keep physical aperture and exposure observed. | A synthetic bar witness distinguishes the expected blur (gradient ratio 0.60), bypass (1.00), and overblur (~0.067). The existing GPU depth-edge fixture also passed on WebGL2. Its focused foreground retained contrast, its defocused background lost contrast, and the known legacy rejection defect increased foreground edge red by 82 bytes versus zero in the current path. A fixture-only f/32 → f/1 fault was rejected by the unchanged GPU check, with 8.54 mean absolute byte error where the correct result is zero. |
| Orientation | Use asymmetric sentinels and expected 180° Raw/Upright mapping. Keep physical film coordinates distinct from display coordinates. | An actual Raw/Upright comparison had mean absolute byte error about 0.000003 under the correct transform versus 37.42 for a deliberately wrong single-axis turn. |
| Teaching readability | Check declared visible ROIs and canonical ray samples in production scenes, and review actual view captures separately. | Historical content changes preserved the measured hero and paving ROI results, even when the global ratio crossed 0.5. |

The negative controls are scoped evidence. Synthetic witnesses qualify comparison logic. The existing depth-edge fixture exercises production-shader behavior. The historical render tap is observational and the altered range is limited to the isolated experiment. Evidence includes `reports/negative-controls.json`, the fixed GPU fixture log/captures, and the exact-source `harness/analyze.py` reducer. **Recommendation for A1.** Preserve current finite/prepared-state, real-render availability and threshold coverage during qualification. Add an explicit request-scoped scene test with a pinned material descriptor and actual execution proof. Qualify fixed-scene local blur/CoC, depth rejection and orientation separately from visual review. Compare old and proposed checks side by side, with malformed, blank, stale, bypass, wrong-blur and wrong-orientation controls and legitimate background changes. Once those checks are proven, keep the global ratio as a descriptive metric or as a fixture-specific expectation. There is no evidence-based all-scene replacement threshold.
