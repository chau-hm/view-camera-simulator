# Runtime parity expectations

Future integration must preserve source geometry/silhouette, metric UV phase, semantic boundaries, frozen neutral ownership, material hierarchy, restrained red/render frequency, opaque covered fields, coherent Prow transitions and doorway hierarchy. It must not reinterpret held zones or add FCC, weathering, interiors or reflection tricks.

The Stage 2G actual Three GLB is Stage 2H's runtime baseline. Merged arrays, maps and material values match exactly. Very small raster differences can occur when draw/depth ordering changes; they are recorded rather than concealed. Exposure, camera projections and common samplers remain documented. Only runtime camera-motion view matrices vary in the trajectory test.

Stage 2F Cycles is upstream appearance authority, not a pixel equality target. Three PMREM/IBL lacks the same indirect occlusion/interreflection. LTC area lights do not cast the same DISK shadows. Shadow-map bias/filtering, Fresnel/transmission, antialiasing and tone/display handling differ. Stage 2G demonstrated flatter recess/trim shading in Three. Stage 2H applies no color, roughness or frequency compensation to chase Cycles.

Hard invariants are architectural/material semantics and stable hierarchy. Sky tint, reflected intensity, indirect depth shading and cast-shadow softness are renderer/environment dependent. Integration must document neutral exposure and environment policy, not introduce per-environment materials. Glass remains a coarse transmission placeholder with opaque fallback limitations.

The environment probes, lights/cameras and performance controls belong to this standalone lab, never to the asset package or simulator canonical state. Only PROW and LOWER_ALBERT_OBLIQUE are stable production candidates; contextual held geometry receiving light gains no maturity.
