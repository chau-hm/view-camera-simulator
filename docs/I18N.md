# Internationalization foundation

The application uses bundled `i18next` resources with `react-i18next` for
learner-facing site, public-catalog, and migrated simulator teaching copy.

## Current contract

- Supported locales are `en` and `zh-HK`; English is the default and fallback.
- Initial resolution is a valid persisted preference, then the browser
  language (`zh`, `zh-*`, and `zh-TW` map to `zh-HK`), then English.
- The preference is stored as the locale identifier under
  `view-camera-simulator.locale` when storage is available.
- Message keys describe semantic UI concepts such as
  `home.focusCta.title` and `scenes.mirrorShift.description`; English
  sentences are not keys.
- English resources define the canonical message shape. Each locale module is
  checked against that shape with TypeScript.
- Translated strings are presentation data only. Scene IDs, routes, task IDs,
  evaluator logic, and simulator state continue to use stable identifiers.

Resources are split by surface under `src/i18n/messages/<locale>/`. Add a new
message to the English module first, then add the equivalent message to every
supported locale module. Keep the pedagogical and terminology contract in
[`LEARNING_MODEL.md`](./LEARNING_MODEL.md) authoritative when translating.

## zh-HK terminology contract

- `large format camera` and explanatory uses of `view camera` use `大片幅相機`.
  Keep the product name `View Camera Simulator` unchanged.
- `camera movements` means technical standard movements and uses `相機移軸`.
  Individual named movements retain established terms such as `前組上移`,
  `前組傾斜`, `前組擺動`, and `前組橫移`.
- `whole-camera movement` means physical relocation of the complete camera and
  uses `整部相機移動`; `move the whole camera` uses `移動整部相機`.
  `相機移軸` must not describe this physical relocation, because it would erase
  the distinction between viewpoint movement and standard movement.

The locale state is global and persists while navigating into the full-bleed
simulator. The language selector is available in both the shared site header
and the simulator header. Free Practice teaching copy, Movement Help, Guided Task
presentation, and the learner-facing Current Settings and Focus Targets
readouts use simulator message catalogs. The readout surface is selected by
stable scene identity at the presentation boundary: state remains
locale-neutral, and scenes without learner focus targets do not render an
empty Focus Targets card. Task and evaluation layers emit locale-neutral
message references; `TaskPanel` and `FeedbackPanel` translate them at render
time, while evaluator facts remain locale-independent. Diagnostics and the
remaining simulator controls remain deferred; translation remains
presentation-only.
