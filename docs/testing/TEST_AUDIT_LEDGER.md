## Classification key and evidence standard

| Code | Judgment |
|---|---|
| **R** | Retain. The declaration protects a distinct contract or evidence-infrastructure rule. |
| **F** | Fix inadequate or misleading proof before relying on the claim. |
| **C** | Consolidate only overlapping proof after the named keeper fails on the original defect. |
| **D** | Delete only after a caller search and preservation proof show no independent contract is lost. |
| **NEEDS_EVIDENCE** | Current evidence is insufficient for a reliable R/F/C/D judgment. |

R/F/C/D applies to tests or coherent parameterized test groups. Workflow invocation judgments are called out separately. A synthetic report mutation is evidence for an evaluator contract; it is not runtime proof of what the browser or renderer did. A diagnostic attribute and a screenshot of matching dimensions do not establish correct raster output unless the assertion observes that output independently.
