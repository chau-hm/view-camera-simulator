# Blind Pair Review Guide

Review the [Interior Corner pairs](blind-pairs-interior-corner.png) and [Shelf Swing pairs](blind-pairs-shelf-swing.png) before opening the [answer key](blind-pair-answer-key.md). Each pair is shown side by side at the normal 514 × 411 Observer display size. Use the left panel as A and the right panel as B. Do not zoom, enlarge, or consult the labeled seed grid until you have recorded each response.

For each pair, record:

1. Did anything change? **Yes / No / Unsure**
2. What changed? Note object count, silhouette, palette, placement, rug treatment, or other visible details.
3. Which composition feels more coherent? **A / B / Equal / Unsure**, with one short reason.
4. Would the change make you inspect the scene or try a different framing/focus setting? **Yes / Maybe / No**, with one short reason.

Keep these answers qualitative; there is no combined score. Record display size and any viewing conditions that affected your judgment. No independent human responses have been collected for this audit; these sheets and prompts are provided for follow-up review.
